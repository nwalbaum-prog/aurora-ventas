Cómo instalar Evolution API

Evolution API es un servidor gratuito y open-source que conecta tu número de WhatsApp mediante QR (como WhatsApp Web) y expone una REST API.

1
Instala Node.js 18+ desde nodejs.org
2
Descarga Evolution API:
npm install -g @evolution-api/server
o usa Docker:
docker run -p 8080:8080 atendai/evolution-api:latest
3
Crea la instancia "aurora":
POST http://localhost:8080/instance/create
body: {"instanceName":"aurora","integration":"WHATSAPP-BAILEYS"}
4
Ingresa la URL, API key e instancia arriba → Guardar y conectar → Escanea el QR con tu WhatsApp
5
Una vez conectado, Aurora Bakers enviará los mensajes directamente desde tu número

Configurar Gmail

Gmail requiere una Contraseña de aplicación (no tu contraseña normal).

1
Activa verificación en 2 pasos en tu cuenta Google
2
Ve a Seguridad → Contraseñas de aplicación
3

4
Configuración:
Host: smtp.gmail.com
Puerto: 587
Usuario: tu correo Gmail completo
También funciona con Outlook (smtp.office365.com:587) o cualquier proveedor SMTP.
